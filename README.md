# Agent Investigator
Ramble Ventures 2026-2027 webmaster project: a spy-themed AI-literacy site for grades 9-12 with a lesson pathway and a rooftop obstacle-course game.

- `index.html` – the built single-file site (open directly or serve with GitHub Pages)
- `src/` – source parts; run `./build.sh` to rebuild `index.html`
- `tests/` – Playwright bot that plays all courses

Not built yet: Firebase accounts/streak sync, real leaderboards, full lesson content.
